# About Awesome Vector Databases

Awesome Vector Databases is a curated, continuously updated directory of vector databases and the wider ecosystem around similarity search and embeddings — the storage layer behind retrieval-augmented generation (RAG), semantic search and recommendation systems.

## What you'll find here

- **Vector databases** — purpose-built, managed, embedded, edge and GPU-accelerated options.
- **Hybrid and extended stores** — Postgres vector extensions, search-engine plugins and multimodal stores.
- **Libraries and resources** — ANN indexing libraries, benchmarks, tutorials and reference material.

## How the directory is maintained

The directory is built and maintained with the [Ever Works](https://ever.works) platform. AI agents research new projects, keep existing listings current and organize everything into categories and tags; every listing links back to its original source.

Missing a database or library? Use the **Submit** page to suggest it.
